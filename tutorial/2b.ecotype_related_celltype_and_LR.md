After defining ecotypes, the next important step is to characterize the
biological features associated with each ecotype.

In SpaNiche, two major aspects are typically investigated:

-   Representative cell types enriched within each ecotype
-   Representative ligand-receptor (LR) interactions

These analyses help reveal the cellular composition and communication
patterns underlying each spatial ecotype.

### Representative cell types

The following code summarizes the cellular composition of each ecotype
and identifies representative cell types.

For each ecotype, the frequencies of all constituent cell types are
aggregated. The relative proportion of each cell type is then calculated
with respect to the total cell-type frequency within the ecotype. Cell
types meeting both of the following criteria are considered
representative:

-   Frequency ≥ 5
-   Relative proportion ≥ 10%

The resulting table can be used to identify dominant cellular
populations associated with each ecotype.

    plotdata = plotdata %>% filter(Freq > 2)
    plotdata$ecotype = paste0("ecotype: ",plotdata$cluster)
    plotdata$ecotype = factor(
      plotdata$ecotype,
      levels = paste0("ecotype: ",intersect(1:1000,unique(hcinfo$cluster)))
      )


    maintype_color = hue_pal()(6)
    names(maintype_color) = c("B","Epi","Mast cells","mye","stromal","t")

    for (ei in levels(plotdata$ecotype)) {
      smallpd = plotdata %>% filter(ecotype == ei)
      loopv = unique(smallpd$loop)
      
      for (li in loopv) {
        smallsmallpd = smallpd %>% filter(loop == li)
        if (li == "center") {
          # No adjustment is needed for the center loop
        } else {
          tmpnum = nrow(smallsmallpd)
          smallsmallpd$x = (10 / tmpnum) * (1:tmpnum)
        }
        plotdata2 = rbind(plotdata2,smallsmallpd)
      } # End of inner loop
    } # End of outer loop

    statdf = data.frame()
    for (ei in as.character(unique(plotdata2$ecotype))) {
      onepd = plotdata2 %>% filter(ecotype == ei)
      one_ecotype_sum = sum(onepd$Freq)
      one_ecotype_stat = onepd %>% group_by(celltype) %>% summarize(Freq = sum(Freq)) %>% as.data.frame()
      one_ecotype_stat$ratio = one_ecotype_stat$Freq / one_ecotype_sum
      one_ecotype_stat = one_ecotype_stat %>% arrange(desc(ratio))
      one_ecotype_stat$ecotype = ei
      one_ecotype_stat$qushe = ifelse(one_ecotype_stat$Freq >= 5 & one_ecotype_stat$ratio >= 0.1,"good","not good")
      statdf = statdf %>% rbind(one_ecotype_stat)
    }
    write.csv(statdf,file = "representative_celltypes.csv",row.names = F,quote = T)

relative proportion, and representative cell-type status for each cell
type within every ecotype.

**Integrating topic-level results across samples**

Because ecotypes are defined across multiple samples, topic-level
results must be aggregated before ecotype-level characterization can be
performed.

The following step collects and merges information from all samples,
including:

-   Topic-associated ligand–receptor interactions
-   LR-induced downstream pathways
-   Topic-specific genes
-   GO enrichment of topic-specific genes

To focus on robust signals, several filtering criteria are applied:

-   LR interaction strength, exp ≥ 3
-   Downstream pathway activation, −log10(p-value) ≥ 3
-   Topic-gene GO enrichment, adjusted p-value ≤ 1e−4

After filtering, the resulting datasets are used for subsequent
ecotype-level aggregation and characterization.

    library(tidyverse)
    library(readxl)
    library(readr)

    gene_num2 = 300
    thre_topic_lr = 3 # Minimum LR interaction strength threshold
    thre_go_res = 3 # Minimum pathway activation threshold (-log10 p-value)
    thre_topic_gene_GO = 0.0001 # Maximum adjusted p-value threshold
    pathdf <- read_excel("D:/hsy/project/202207Xi/06.analysis/CRC/CRC_some_path.xlsx") %>% as.data.frame()

    all_topic_lr = data.frame() # Topic-associated ligand-receptor pairs
    all_go_res = data.frame() # Downstream pathways activated by LR interactions. In the previous step, p-values were filtered using pval < 0.01. These pathways represent downstream responses induced by highly expressed ligand-receptor interactions in a given microenvironment.
    all_topic_gene = data.frame() # Topic-specific high-weight genes; by default, the top 300 genes are retained
    all_topic_gene_GO = data.frame() # GO enrichment results of topic-specific genes
    for (pdi in 1:nrow(pathdf)) {
      tmpres = readRDS(paste0(pathdf$path_out[pdi],"res.list.rds"))
      pathout1 = paste0("./02.lr/",pathdf$sample_name[pdi])
      
      ###
      topic_lr <- read_csv(paste0(pathout1,"/topic_lr_small_0.95.csv"))
      topic_lr = as.data.frame(topic_lr)
      topic_lr$sample = pathdf$sample_name[pdi]
      all_topic_lr=all_topic_lr %>% rbind(topic_lr)
      
      ###
      go_res = tmpres$go_res
      go_res$sample = pathdf$sample_name[pdi]
      colnames(go_res)[9] = "topic"
      all_go_res=all_go_res %>% rbind(go_res)
      
      ###
      topic_gene = readRDS(paste0(pathout1,"/topic_gene.rds"))
      small_tg = topic_gene %>% group_by(topic) %>% top_n(gene_num2,wt = value)

      small_tg$sample = pathdf$sample_name[pdi]

**Ecotype-Level aggregation of biological features**

The final step is to iterate through all ecotypes and aggregate the
associated topic-level information according to ecotype assignments.
Each ecotype consists of multiple sample-specific topics; therefore, all
topics assigned to the same ecotype are collected and summarized.
Additional filtering is then applied to retain robust and recurrent
features.

    hcinfo = read.csv("./01.module/ecotype/hcinfo_anno.csv",header = T)

      onecluster_topic_lr_stat = onecluster_topic_lr_stat %>% filter(len >= 2)

      write.csv(onecluster_topic_lr_stat,file = paste0(pathout2,"/topic_lr_stat_","exp",thre_topic_lr,"len2",".csv"),quote = T,row.names = F) ## Save results

### Summary

By integrating information from multiple samples and multiple topics,
this workflow generates a comprehensive characterization of each ecotype
from four complementary perspectives:

-   Cellular composition (representative cell types)
-   Cell-cell communication (ligand-receptor interactions)
-   Transcriptional programs (high-weight genes)
-   Biological functions (GO enrichment)

Collectively, these analyses facilitate the biological interpretation of
spatial ecotypes and help elucidate the cellular and molecular
mechanisms underlying distinct tissue microenvironments.
